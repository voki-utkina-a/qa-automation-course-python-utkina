# User Management API Simulator

Pet-project для практики Python и PyTest.

## Что используется

- Python
- PyTest
- JSON
- Fixtures
- Parametrize
- Assert

## Возможности

- Загрузка пользователей из JSON
- Поиск пользователя по ID
- Получение активных пользователей
- Получение email пользователя
- Автоматические тесты

## Запуск тестов

pytest -v
